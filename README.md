# Dhayanithi B — Personal Portfolio

Responsive portfolio built with Next.js 14, TypeScript, Tailwind CSS, Framer Motion and Lucide icons.

## Run locally
1. Install Node.js (LTS).
2. Extract this ZIP and open the `dhayanithi-portfolio` folder in VS Code.
3. Open the VS Code terminal in this folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open http://localhost:3000.
